# 問い合わせ管理Demoサイト

## 概要

問い合わせの受付、管理者による一覧確認、詳細確認、ステータス変更、返答内容の保存を行うためのDemoサイトです。

現時点では、HTML / CSS / JavaScript のみで構成した静的サイトとして作成しています。  
データ保存にはブラウザの `localStorage` を使用しており、DBやサーバーサイド処理はまだ使用していません。

## 公開URL

GitHub Pagesで公開する想定です。

```text
https://yuyamitsu.github.io/inquiry-demo/
```

## 作成目的

これまでの「機能を作る」段階から、次のステップとして「設計して作る」ことを目的に作成しています。

問い合わせ管理を題材に、以下の流れを段階的に整理・実装しています。

```text
問い合わせ受付
↓
問い合わせ登録
↓
管理者一覧
↓
問い合わせ詳細確認
↓
ステータス更新
↓
管理者返答
↓
検索・絞り込み
```

## 主な機能

### 利用者側

- 問い合わせフォーム表示
- 名前、メールアドレス、件名、カテゴリ、問い合わせ内容の入力
- 問い合わせ情報の登録
- 登録後、管理者一覧画面へ遷移

### 管理者側

- 問い合わせ一覧表示
- 問い合わせ詳細表示
- ステータス変更
- 管理者返答内容の保存
- キーワード検索
- ステータス絞り込み
- カテゴリ絞り込み
- 検索条件リセット
- 問い合わせ削除
- 件数サマリー表示

## 画面構成

### 1. 問い合わせフォーム

ファイル：

```text
index.html
```

利用者が問い合わせ内容を入力する画面です。

入力項目は以下の通りです。

| 項目 | 内容 |
|---|---|
| お名前 | 問い合わせした利用者名 |
| メールアドレス | 返信先メールアドレス |
| 件名 | 問い合わせのタイトル |
| カテゴリ | 質問 / 相談 / 不具合 / その他 |
| 問い合わせ内容 | 問い合わせ本文 |

### 2. 管理者一覧画面

ファイル：

```text
pages/admin-list.html
```

登録された問い合わせを一覧で確認する画面です。

表示項目は以下の通りです。

| 項目 | 内容 |
|---|---|
| ID | 問い合わせID |
| 件名 | 問い合わせタイトル |
| 名前 | 問い合わせ者名 |
| カテゴリ | 問い合わせ分類 |
| ステータス | 対応状況 |
| 受付日時 | 登録日時 |
| 詳細 | 詳細画面へのリンク |
| 削除 | 問い合わせ削除ボタン |

### 3. 管理者詳細画面

ファイル：

```text
pages/admin-detail.html
```

問い合わせ内容の詳細確認と、管理者対応を行う画面です。

管理者は以下の操作ができます。

- 問い合わせ内容の確認
- ステータス変更
- 返答内容の入力
- 対応内容の保存

## ステータス

問い合わせの対応状況として、以下のステータスを使用しています。

| ステータス | 意味 |
|---|---|
| 未対応 | まだ管理者が対応していない状態 |
| 対応中 | 管理者が確認・対応している状態 |
| 回答済み | 利用者への返答が完了した状態 |
| クローズ | 対応完了として終了した状態 |

## 構成方針

`index.html` はGitHub Pagesで最初に表示されるトップページとして、リポジトリ直下に配置しています。

管理者側の画面は `pages` ディレクトリにまとめています。

CSS、JavaScript、画像などの静的ファイルは `assets` ディレクトリ配下にまとめ、画面ファイルと共通アセットを分離しています。

これにより、画面ファイル・スタイル・スクリプトの役割を分けて管理できる構成にしています。

## データ保存について

現在はDBを使用せず、ブラウザの `localStorage` に問い合わせデータを保存しています。

そのため、問い合わせデータはサイトを開いた利用者のブラウザ内にのみ保存されます。

```text
自分のブラウザで登録した問い合わせ
→ 自分のブラウザに保存される

他の人のブラウザで登録した問い合わせ
→ その人のブラウザに保存される
```

現時点では、複数ユーザー間で問い合わせデータを共有する構成ではありません。

## 動作確認手順

### 1. 問い合わせを登録する

`index.html` を開き、問い合わせフォームに以下のような内容を入力します。

```text
お名前：山田 太郎
メールアドレス：yamada@example.com
件名：料金について
カテゴリ：質問
問い合わせ内容：料金プランを教えてください。
```

送信後、管理者一覧画面へ遷移します。

### 2. 一覧画面で確認する

`pages/admin-list.html` で、登録した問い合わせが一覧に表示されることを確認します。

### 3. 詳細画面で確認する

一覧の「詳細」を押し、`pages/admin-detail.html` に遷移します。

問い合わせ内容が表示されることを確認します。

### 4. ステータスを変更する

詳細画面でステータスを変更し、返答内容を入力して保存します。

例：

```text
ステータス：対応中
返答内容：お問い合わせありがとうございます。確認いたします。
```

保存後、一覧画面に戻り、ステータスが変更されていることを確認します。

### 5. 検索・絞り込みを確認する

一覧画面で以下の検索を確認します。

- キーワード検索
- ステータス絞り込み
- カテゴリ絞り込み

### 6. 削除を確認する

一覧画面の削除ボタンを押し、対象の問い合わせが削除されることを確認します。
